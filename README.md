# Alchemix (ex Aqua-Deluxe)

**Demo online:** [https://mauro-cuquejo-tupad.github.io/aqua-deluxe/](https://mauro-cuquejo-tupad.github.io/aqua-deluxe/)

Este es un preproyecto que estoy desarrollando bajo el nombre de **Alchemix** (anteriormente Aqua-Deluxe).

El código inicial fue generado con Gemini, por lo que seguramente haya bastante margen para optimizarlo y mejorar su estructura. Mi intención fue evitar el uso de librerías innecesarias, buscando que el proyecto sea fácil de retomar, mantener y escalar.

Siéntanse libres de explorar el código y desarrollar sus propias versiones.

Por el momento, se trata de una demo funcional que representa una primera aproximación a lo que será mi juego en **Godot** en el futuro.

Pueden probarlo directamente desde GitHub Pages e incluso instalarlo como aplicación desde su navegador de preferencia para visualizarlo en dispositivos móviles.

No llegué a probar todas las resoluciones posibles, pero intenté adaptar la interfaz para que se visualice de la mejor manera posible en pantallas de dispositivos de 5 pulgadas en adelante.

Como suele suceder con el código generado mediante IA, las interfaces todavía están algo sobrecargadas y necesitan una buena pasada de limpieza y simplificación. Aun así, el juego es completamente funcional y jugable.

**Estado del desarrollo:** al momento de escribir esto, voy por el nivel 60 de un total de 100, por lo que es posible que todavía haya cambios y ajustes.

¡Saludos!
